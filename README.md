# PharmaCiclo

Protótipo web do projeto **PharmaCiclo: Reciclando Saúde**, voltado para a conscientização e orientação sobre o descarte correto de medicamentos vencidos.

## Funcionalidades

- Mapa interativo com pontos de descarte próximos (Leaflet + JSON local)
- Busca por CEP para centralizar o mapa
- Interface moderna com barra de navegação e conteúdo educativo

## Tecnologias usadas

- HTML, CSS e JavaScript
- Leaflet.js
- OpenStreetMap + Nominatim API

## Objetivo

Promover a saúde pública e sustentabilidade, alinhado aos ODS 3 e ODS 11.

---

*Este projeto é um protótipo educacional sem fins comerciais.*
