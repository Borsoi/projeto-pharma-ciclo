# PharmaCiclo 🌿💊

**PharmaCiclo: Reciclando Saúde** é um protótipo web desenvolvido para promover a conscientização sobre o descarte correto de medicamentos vencidos, contribuindo para a saúde pública e a sustentabilidade ambiental.

🔗 **Acesse o protótipo aqui:**  
👉 [https://borsoi.github.io/projeto-pharma-ciclo/](https://borsoi.github.io/projeto-pharma-ciclo/)

---

## 🗺️ Funcionalidades

- Mapa interativo com pontos de descarte próximos (usando Leaflet e JSON local)
- Busca por CEP com centralização dinâmica no mapa
- Interface moderna e responsiva com:
  - Barra de navegação estilizada
  - Conteúdo informativo sobre os impactos do descarte inadequado

---

## 🛠️ Tecnologias Utilizadas

- HTML, CSS e JavaScript puro
- [Leaflet.js](https://leafletjs.com/) para o mapa
- [OpenStreetMap](https://www.openstreetmap.org/) + [Nominatim API](https://nominatim.org/) para geolocalização

---

## 🎯 Objetivo

O projeto visa impactar positivamente as comunidades com:

- Acesso fácil a locais de descarte de medicamentos
- Educação sobre riscos ambientais e de saúde
- Apoio aos **ODS 3 - Saúde e Bem-Estar** e **ODS 11 - Cidades e Comunidades Sustentáveis**

---

> ⚠️ *Este projeto é um protótipo educacional, sem fins lucrativos ou comerciais.*
